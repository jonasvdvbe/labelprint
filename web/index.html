LabelPrint – quick help

  1. Choose your printer. The print method is suggested from the driver name. Zebra (e.g. GK420d) → ZPL. TSC/Xprinter/Munbyn → TSPL. Old Zebra LP/TLP 2844 → EPL2. Dymo, Brother and anything else → Windows driver (set the label size in the driver's printing preferences).
  2. Set the label size and resolution (GK420d: 203 dpi, max 104 mm wide).
  3. Open or drop a PDF. The label is detected on each page. If the detection is wrong, pick a fixed area (e.g. “Top-left quarter”) or drag a rectangle on the page. Save it as a preset per carrier.
  4. Check the preview on the right – that's exactly what will be printed – then press Print (Ctrl+P).

Labels print shifted or skip a label? Use Calibrate media, set Media to “Labels with gap”, or use the shift settings.

Open with… You can right-click a PDF → Open with → LabelPrint.exe, or drag PDFs onto the .exe.
